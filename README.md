# Unversal Converter

Alat sederhana untuk mengonversi gambar menjadi PDF.

Repository ini berisi skrip Python dan artefak build (PyInstaller).


Untuk Membuat  applikasinya lakukan step berikut :
Jangna lupa : pip install pyinstaller

    1. Ke terminal
    2. ketik : pyinstaller --onefile UConv.py (Dengan console)
    3. Ketik : pyinstaller --onefile --windowed UConv.py (Untuk USer)
